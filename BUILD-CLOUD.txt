The Build and release ihatemeetings workflow compiles Windows x64 and universal
macOS binaries, validates them and publishes the versioned release artifacts.
Version 1.5.2 is published in Releases with the Windows EXE and universal Mac DMG
listed first, followed by the alternate app ZIP, source archives and checksums.
The workflow also runs platform layout regression checks before compilation so
known window/control spacing regressions fail the build. Users installing the app
do not need to run a build command.
