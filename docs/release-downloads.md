## What's included

Version 1.5 adds Advanced mode with five persistent app-specific packet/flow presets and an app traffic inspector. Each preset can match application, TCP/UDP, direction, local port, remote IP/CIDR and remote port while using the existing timing, random-range, cycle and hotkey controls.

Windows scopes Advanced rules with the executable identity directly. Mac scopes them to exact active connection tuples owned by the selected executable. Existing Fast, Adapter, Zoom and Meet modes remain available.
