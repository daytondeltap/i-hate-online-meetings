## What's included

Version 1.5.1 expands and reflows both native interfaces to prevent overlapping or clipped controls, including the Advanced packet-filter editors. The build pipeline now also checks the expected minimum window sizes and known layout gaps before release.

Advanced mode keeps five persistent app-specific packet/flow presets and an app traffic inspector. Each preset can match application, TCP/UDP, direction, local port, remote IP/CIDR and remote port while using the existing timing, random-range, cycle and hotkey controls.

Windows scopes Advanced rules with the executable identity directly. Mac scopes them to exact active connection tuples owned by the selected executable. Existing Fast, Adapter, Zoom and Meet modes remain available.
