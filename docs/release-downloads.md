| **Mac — Apple Silicon or Intel** | [**Download for Mac (.dmg)**](https://github.com/daytondeltap/zoom-breaker/releases/download/v1.4.0/02-Mac-ihatemeetings.dmg) | Open the disk image and drag **ihatemeetings** into **Applications**. |

**No build commands or developer tools required.** Windows 10/11 x64; macOS 12+.

Windows is unsigned. Mac is ad-hoc signed, not Apple-notarized; first launch may require **System Settings → Privacy & Security → Open Anyway**.

## What's included

Meet Lag and Meet Disconnect/hold, independent randomized OFF/ON ranges, compact native controls and an app icon. Includes automatic cycles, unlimited runs, manual hotkey toggling, Zoom modes and adapter modes.

Both platforms passed compilation and automated checks. Mac checks include universal architectures, PF rule syntax, signature and DMG verification. Live UI, adapter and Zoom/Meet call behavior remain unverified by these checks.

Meet filtering affects known media destinations and does not guarantee removal from a meeting. Windows scopes it to supported browsers; Mac scopes it to all apps on the selected adapter. Mac Zoom state refresh may affect other connections to the same remote address.
