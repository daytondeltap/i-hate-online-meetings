IHATEMEETINGS 1.5.2 VALIDATION

Release CI gates: Windows warnings-as-errors build, 25 cycle/timing cases,
Windows and Mac layout checks, Mac timing and app-isolation parser tests,
PF rule syntax check, universal Mac build, signature and DMG verification.

New regression cases cover separate apps connecting to the same server,
shared UDP ports, exact PF state IDs, ambiguous/NAT states, IPv6 endpoints,
and CIDR boundaries. They validate model behavior, not live packet delivery.

Not verified by hosted CI: physical adapter behavior, interactive hotkeys,
actual Zoom/Meet interruptions, every DPI setting, or end-to-end live
cross-application isolation. Mac ownership remains best-effort because PF
matches connection tuples rather than executable identity.
