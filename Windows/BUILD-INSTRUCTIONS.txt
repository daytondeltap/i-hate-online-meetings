ihatemeetings.exe is already compiled in the 1.5.2 release. Run it directly for normal use.

Optional local rebuild:
Run COMPILE-WINDOWS.cmd with a Windows MinGW-w64 toolchain installed, or use
source/Build-ihatemeetings.ps1. The build helper first generates the expanded
Advanced/UI layout source, validates the expected geometry, then compiles it so
Advanced mode and the base modes are included in the same native executable.

Cloud build:
This repository includes the "Build and release ihatemeetings" GitHub Actions
workflow. It runs the timing tests and Windows/macOS layout regression checks,
compiles the Windows x64 executable, builds and verifies the universal macOS
app/DMG, packages source archives and publishes the versioned release when that
release tag does not already exist.

Version 1.5.2 has been built and published. Installers are on the Releases page;
rebuilding is only needed for development or later source changes.
